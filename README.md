# 🎓 Academia de Marketing Digital

Este é um site de vendas de cursos online focado em **marketing digital e renda online**.  
O objetivo é ajudar iniciantes a aprender estratégias simples para ganhar dinheiro usando apenas o celular.

---

## 🚀 Sobre o projeto

A **Academia de Marketing Digital** é uma plataforma criada para:

- Vender cursos online via WhatsApp 📲
- Ensinar marketing digital para iniciantes
- Mostrar conteúdos práticos e diretos
- Gerar renda através de infoprodutos

---

## 🖥️ Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- Design responsivo

---

## 📌 Estrutura do site

O site está organizado em seções:

- **Hero (Página inicial)** → Apresentação e botão de compra via WhatsApp
- **Sobre o fundador** → Introdução do criador do projeto
- **O que você vai aprender** → Conteúdos dos cursos
- **Cursos disponíveis** → Categorias de cursos
- **Depoimentos** → Provas sociais
- **Contador de promoção** → Urgência de compra
- **Botão WhatsApp flutuante** → Acesso rápido para vendas

---

## 💰 Como funciona a venda

As vendas são feitas diretamente pelo WhatsApp:

👉 Usuário clica em **“Comprar pelo WhatsApp”**  
👉 Entra em contacto direto com o vendedor  
👉 Finaliza a compra de forma simples
